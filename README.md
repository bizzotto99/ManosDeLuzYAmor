# ManosDeLuzYAmor

Sitio web de sanación energética y espiritual desarrollado con Next.js.

## Descripción

Manos de Luz y Amor es una plataforma web que presenta servicios de sanación energética, armonización y limpieza de espacios. El sitio está diseñado con un enfoque espiritual y moderno, utilizando tecnologías web actuales.

## Tecnologías

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Radix UI

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

El servidor se iniciará en `http://localhost:3000` (o el puerto especificado).

## Scripts Disponibles

- `npm run dev` - Inicia el servidor de desarrollo
- `npm run build` - Construye la aplicación para producción
- `npm start` - Inicia el servidor de producción
- `npm run lint` - Ejecuta el linter

## Estructura del Proyecto

```
├── app/              # Páginas y layouts de Next.js
├── components/       # Componentes React
│   ├── landing/     # Componentes de la landing page
│   └── ui/          # Componentes UI reutilizables
├── public/          # Archivos estáticos
└── styles/          # Estilos globales
```
